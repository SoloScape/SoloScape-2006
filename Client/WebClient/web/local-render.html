SoloScape — browser-local renderer (experimental)

This is not the existing PNG stream. It attempts to run the actual Java 443 client inside your phone's browser using CheerpJ (WebAssembly). Your Linux machine still runs the game server.

Sign in to Tailscale to connect
Enter your Linux server's Tailscale IP and start the experiment. The Java client, not the streaming bridge, will run on this device.

Requires a Tailscale-connected game server, browser sign-in, a staged client JAR and cache, and access to the CheerpJ runtime CDN. Never put a Tailscale authentication key in this HTML. On phones, Java AWT performance and touch controls are not yet verified. The original streamed client is still available on port 8081.
