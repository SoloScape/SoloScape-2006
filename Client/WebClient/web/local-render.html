SoloScape — browser-local renderer (LAN experiment)

The revision-443 Java client runs and renders in your browser via CheerpJ. Your Linux machine runs the unchanged game server and a lightweight WebSocket-to-TCP relay. No Tailscale or external game-server access is needed.

Game connection: to Linux TCP 127.0.0.1:43594

Start the experiment with the game server running on Linux.

Experimental: audio is disabled to prevent a loading freeze. A full mobile play session, Java AWT rendering and touch controls are not verified. CheerpJ still downloads its runtime from its external CDN, so internet access is required for uncached assets. Keep port 8082 LAN-only; do not port-forward it. The original streamed client remains on port 8081.
